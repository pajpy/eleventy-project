# Dinosaur Herbivores

Herbivorous dinosaurs were plant-eating animals. They fed on leaves, ferns, trees, and other prehistoric vegetation.

Many herbivores developed special defenses because they were often hunted by predators. Some were protected by size, others by horns, armor, or spikes.

## Common Features

- Plant-based diet
- Large bodies
- Defensive structures
- Herd behavior
- Specialized teeth for eating plants

## Famous Dinosaur Herbivores

- Triceratops
- Stegosaurus
- Brachiosaurus
- Ankylosaurus

Herbivores were essential to prehistoric ecosystems because they shaped plant life and served as prey for carnivorous dinosaurs.

##  JavaScript Example

The following JavaScript code stores the name of a herbivorous dinosaur and displays it in the console.

```js
const dinosaur = "Triceratops";

console.log("Herbivore dinosaur:", dinosaur);
```
